# Asal sumber

Proyek ini melanjutkan dua kelas JDBC pada folder lokal `backend-rafik/Backend`: `db.DatabaseConnection` dan `appData.showData`. Salinan `backend_vapezoo` memiliki koneksi yang sama dan logika pembacaan yang sama; perbedaan utamanya pemenggalan baris output.

Versi asal membaca seluruh tabel `category` pada MySQL. Versi ini mempertahankan tujuan pembacaan kategori, menambahkan pencarian dan pilihan ID, memperbaiki penutupan resource, serta memindahkan konfigurasi dari source ke environment. Schema dan kategori yang disertakan adalah contoh baru, bukan ekspor database pengguna.

Tidak ditemukan pernyataan lisensi pada dua file sumber asal. Repository ini tidak menambahkan klaim lisensi atau kepengarangan eksklusif atas kode asal.
